# Archive

This folder contains historical breast-cancer scripts and outputs that are not part of the canonical modeling or deployment workflow.

The active workflow is organized as:

```text
01_data_cleaning/
02_data_preprocessing/
03_model_training_and_evaluation/
04_model_deployment/
05_github_publishing/
```

The archived `_utils.py` supported the historical scripts in `legacy_scripts/`. It is not imported by the current application or the current training pipeline.
